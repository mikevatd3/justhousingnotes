# LLM Interpretability

This project has a few quarto notebooks exploring neural networks, transformers,
and interpretability techniques.

## Setup

### Quarto

Quarto is a way to publish dynamic documents that combine text, code,
visualizations [Here](https://quarto.org/docs/get-started/) are the installation 
instructions.

### Python package setup

This project uses `uv` for dependency management. Here are the [installation
instructions](https://docs.astral.sh/uv/getting-started/installation/). Once
`uv` is installed, you can install the package by running `uv sync` from the
root of this project.
